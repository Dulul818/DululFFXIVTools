# Thank Helper

Thank Helper 是一个面向 **Dalamud API 15** 的 FF14 坦克辅助插件，提供静默自动打断、自动冲刺、倒 T 自动挑衅、无敌提醒，以及依赖 vnavmesh 的自动聚怪和小怪智能避让。

## 通过 Dalamud 自定义仓库安装

1. 打开 Dalamud 的“插件安装器”。
2. 打开插件安装器的“设置”，找到“自定义插件仓库”（Custom Plugin Repositories）。
3. 添加并保存以下精确 URL：

   ```text
   https://gh.atmoomen.top/raw.githubusercontent.com/Dulul818/DululFFXIVTools/main/pluginmaster.json
   ```

4. 返回插件安装器，搜索 **Thank Helper** 并安装。
5. 如需启用自动聚怪，请同时安装并启用 **vnavmesh**。

## 主要功能

- 支持骑士（PLD）、战士（WAR）、暗黑骑士（DRK）和绝枪战士（GNB）。
- **自动打断**：不切换目标，优先使用插言；插言不可执行时才考虑已确认的下踢。支持本地下踢学习、策展数据同步和分享码导入导出；未知试探默认关闭，Boss 不参与未知试探。
- **自动冲刺**：脱战后按设置自动冲刺。
- **倒 T 自动挑衅**：八人本中一仇 T 死亡后自动开启盾姿并挑衅 Boss，默认关闭。
- **无敌提醒**：支持四坦克无敌，暗黑骑士额外支持“死而不僵”提醒。
- **自动聚怪**：在小怪战斗中规划短距离收束；普通模式达到公共 AOE 覆盖后停止，极致压缩允许一次有明显收益的额外收束。
- **智能避让**：识别小怪的圆形、扇形和直线危险读条，结合插言/下踢冷却、黑盾和无敌覆盖选择等待或近距离避让。
- **手动接管与断连保护**：玩家移动会立即停止自动路径；vnavmesh 断连会停止并暂停自动聚怪，恢复后重新停车计时并自动继续。
- BossRank Boss 处于可攻击或战斗状态时，自动聚怪和小怪智能避让暂停。
- PvP 中相关战斗自动化强制停止。

## 命令

```text
/thankhelper
/thankhelper interrupt
/thankhelper probe
```

## 风险提示

自动聚怪必须依赖 vnavmesh 的导航网格和路径执行。请先在低风险 PvE 场景验证，并保持未知下踢试探关闭，直到你确认当前游戏、Dalamud 和 vnavmesh 版本的行为符合预期。任何时候都可以用玩家移动输入接管。
